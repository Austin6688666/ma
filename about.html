寻找同频旅人 · 集团联合招募

山海共生集团为员工提供公平、安全且尊重个人价值的人文雇主环境。我们在咖啡、旅宿、中餐各板块寻找对风土地理心存敬畏、对邻里社区满怀温情的伙伴。这不仅是一份工作，更是一场关于风味与人情的美好旅程。

山海共生 · 集团品牌理念

“同一片土地，三种体验，一个完整的海南。”
我们坚信，无论是18°D咖啡所专注的“澄迈火山玄武岩红土豆”、汐澜中餐所坚守的“海岸线时令食材”，还是亚美旅宿所秉持的“山海间的安静落脚处”，都在以各自的日常美学，致敬脚下这片富饶的风土。在集团的大家庭里，我们用人文善意搭建起全链路的暖心无障碍通道与关怀。我们招募的不是雇员，而是与自然和谐共生、对邻里满怀温暖的同路旅人。

精品咖啡师 / 风味研究员

全职 / 兼职 // 18°D COFFEE

负责科学金杯手冲与特调咖啡的萃取，深入倾听宾客偏好并提供风味定制，以温暖、适度的服务礼仪接待店内的每一位邻里。

职位要求
  • 拥有SCA中级或以上认证者优先，但更看重您对咖啡的纯粹热爱；
  • 具备极强的共情与主动沟通能力，认同且愿意践行“十秒微笑原则”；
  • 熟练掌握手势点单，愿意与我们的听障“无声咖啡师”伙伴包容协作。

「无声咖啡师」风味共创者

全职 (残障人士通道) // 18°D COFFEE

面向听障、语障等特殊群体开放。由集团全额资助完成300小时国际SCA专业资质证书培训。通过考核后，可独立研制手冲及意式配方，以专业技能赢取行业认可与研发提成。

职位要求
  • 欢迎听觉或言语障碍人士申请，门店提供完善 of 无障碍工作流程；
  • 具有咖啡冲煮热情，有无经验均可，提供全面且有薪的专业师带徒培训；
  • 具有温暖阳光的笑容，能适应团队的友善静音协作。

海岸空间体验主理人 (店店长)

全职 // 18°D COFFEE

统筹门店的整体运营，监督落实以人为本的服务标准，管理气象应急备品，策划社区公益与宠物友好活动。

职位要求
  • 2年以上精品咖啡或中高端服务业店长经验，懂咖啡，更懂人情；
  • 关注海棠湾本地气象与潮汐，能从细节上周全调度海岸气象应急服务；
  • 善于团队包容性管理，能将员工与宾客的尊严与快乐放在运营首位。

亚美旅宿 - 人文房务与环保管家

全职 // YAMEI HOTEL

负责旅宿的日常房务美学维护与绿色运营。贯彻零废弃环保管理，向住客传递生态共生理念，并积极参与社区人文公益与无障碍服务。

职位要求
  • 具有温暖的微笑和真诚服务的同理心，时刻保持对旅人的人文关怀；
  • 认同自然共生理念，乐于向宾客科普旅宿的富硒红土与雨水循环等设计；
  • 具备团队协作意识，包容并尊重多元文化与特殊住客的特殊需求。

汐澜中餐 - 地缘风物创意主厨

全职 // SILAN BISTRO

负责餐厅时令创意菜品的研发与烹饪。挖掘海南富硒红土、近海野生的地缘风物潜能，推行厨房零塑与零碳减排记录，用火候表达人文与风土。

职位要求
  • 3年以上高端中餐厅或创意菜主厨经验，对川粤火候有独到理解；
  • 热爱自然与本真味道，乐于前往合作基地直采风物，理解并支持小农；
  • 支持厨房有机堆肥与低碳环保计划，能将低碳减碳指标与极致美味完美融合。
